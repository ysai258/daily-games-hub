# Daily Games Hub

One link for our daily games: Absolute Cinema, Aadu Gajala, Evarra? and Pattukunte
Pattucheera. Play each game on its own site, paste its share text here, and see
today's leaderboard.

```bash
npm install
npm run dev   # http://localhost:3000, with an embedded database and no setup
```

> This leaderboard is for our friend group. Results are pasted by players
> (self-reported) and are not tamper-proof.

- `FEASIBILITY.md`: why results are pasted rather than read automatically
- `IMPLEMENTATION_SUMMARY.md`: architecture, API, schema, deploy steps, limitations
